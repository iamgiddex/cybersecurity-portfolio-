
## Summary
This is a written theory assignment (50 marks). It covers how Application Control and URL Filtering work together in the Access Control Policy, how each identifies what it controls, the four rule use cases, and the five-step deployment workflow. No practical configuration was required.

## Sections
| Section | Content | Marks |
|---|---|---|
| A | Ten short-answer questions (purpose, signatures, URL database, benefits, use cases, default services, custom categories) | 20 |
| B | Differentiate Application Control and URL Filtering; how they work together; two guidelines with reasons (separate rules, matching on recommended services) | 15 |
| C | Match four company requirements to use cases, granular policies by user or group, and the five-step deployment workflow | 15 |

## Topics covered
- Application Control uses signatures; URL Filtering uses an online category database.
- Use cases: Monitor Applications, Block Applications and Inform Users, Limit Application Traffic, Block Sites.
- Deployment workflow: Plan, Enable, Create rules, Publish, Install Policy.
