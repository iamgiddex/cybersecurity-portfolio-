# Check Point Certified Security Administrator (CCSA)

## Overview

This section documents my practical learning and laboratory exercises in Check Point Security Administration.

The exercises focus on firewall administration, security policy configuration, network objects, access control, Network Address Translation (NAT), and security management.

## Learning Objectives

- Understand Check Point security management architecture.
- Configure and manage network objects and services.
- Develop and organise firewall access control policies.
- Understand firewall rule evaluation and rule ordering.
- Configure and examine Network Address Translation.
- Investigate policy installation errors and troubleshooting procedures.
- Document security configurations and laboratory limitations.
